# Project Idea

ShareFood is a platform where people can give away food with a valid expiration date for free to others in their local community.

The project is inspired by OLIO but focuses on a simple local MVP aimed at validating the concept before investing in a larger product.

---

# MVP Goal

The MVP is intended to validate the following assumptions:

* People are willing to create food listings.
* Other users are willing to collect shared food.
* The interaction flow is simple and convenient.
* A local food-sharing community can be formed.

---

# User Roles

## Guest

Can:

* Browse listings
* Search for food
* Register an account

## User

Can:

* Create listings
* Edit listings
* Delete listings
* Reserve food items
* Message other users
* View their dashboard

---

# Core MVP Features

## 1. Home Page

### Sections

* Hero section
* How the service works
* Latest listings
* Create Listing CTA

### CTA Buttons

* Browse Listings
* Share Food

---

## 2. Registration and Login

### Registration

Fields:

* Name
* Email
* Password

### Login

Fields:

* Email
* Password

---

## 3. Listings Feed

### Listing Card

Contains:

* Photo
* Title
* Description
* District / Area
* Expiration Date
* "I'll Take It" button

### Filters

* Search
* District / Area
* Category

---

## 4. Create Listing

### Fields

* Title
* Description
* Photo
* Expiration Date
* District / Area
* Category

### Allowed Categories

* Fruits
* Vegetables
* Grains & Pasta
* Canned Food
* Drinks
* Sweets

### Prohibited Categories

* Dairy Products
* Meat
* Fish
* Homemade Food
* Alcoholic Drinks

---

## 5. Listing Page

Contains:

* Large Photo
* Full Description
* District / Area Information
* Contact Section
* Contact User Button

---

## 6. User Dashboard

The user can view:

* Their listings
* Reserved food items
* Listing statuses

---

## 7. Messaging System

### MVP Solution

A simple built-in chat inside the platform.

### Benefits

* No need to share phone numbers
* Safer communication
* Users remain on the platform
* Moderation can be added later

---

# Safety Requirements

Do not display:

* Exact address
* Phone number
* Personal information

Display only:

* District / Area
* Approximate location

The exact pickup address is shared later through the chat.

---

# Decision

The first version of ShareFood will be developed with only the features described in this document.

Any additional functionality will be postponed until MVP validation is completed.
